# Локальні шрифти та погоджене виправлення контрасту

## Проблема

Preview для повторних записів не зібрався через `Can't resolve '@vercel/turbopack-next/internal/font/google/font'`. Точну причину всередині залежності не встановлено. Виправлення прибирає завантаження Google Fonts під час збірки без оновлення Next.js чи залежностей.

Повносторінкова перевірка додатково виявила старі проблеми контрасту: підпис Buy (2,42:1), опис Buy (3,69:1), підпис Rent (3,63:1). Роботу було зупинено; 2026-11-09 користувач погодив мінімальне затемнення цих трьох текстів. Правила axe не вимикалися.

## Реалізація та файли

- `src/app/(frontend)/layout.tsx`: `next/font/local` замість Google; ті самі Inter, Cormorant Garamond, CSS-змінні, товщини та `display: swap`.
- `src/assets/fonts/`: чотири незмінені офіційні WOFF2, дві ліцензії OFL, `manifest.json` із зафіксованими джерелами/SHA-256 та `README.md`.
- `src/components/boutique/journey-split.tsx`: наявний `text-brand-charcoal` для двох підписів і опису Buy. Опис Rent, фони, посилання, розмітка й відступи не змінені. Компонент спільний для головної та `/dresses`.
- `tests/int/local-fonts.int.spec.ts`: шість перевірок підключення, цілісності й ліцензій.
- `tests/e2e/local-fonts.e2e.spec.ts`: шрифти, відсутність запитів Google Fonts, переповнення й axe на `/`, `/dresses`, `/book-a-fitting` при 1440px і 390px.
- Цей звіт та шість скриншотів `docs/changes/font-build-*.png`.

Згенеровані `src/payload-types.ts` і `src/app/(payload)/admin/importMap.js` не мають змістових змін; не включати зміни лише закінчень рядків у коміт.

## Міграція та відкат

Нових міграцій, індексів чи перетворень даних немає. Наявні 16 міграцій master застосовано лише для підготовки тимчасової локальної бази. Production не використовувався.

Відкат: повернути зміни focused PR і повторно розгорнути застосунок. Відкат даних не потрібен. Повернення Google Fonts може повернути первинний збій збірки; повернення старих кольорів відновить порушення контрасту.

## Перевірки — 2026-11-09

- `npm ci --no-audit --no-fund`: успішно під час підготовки окремої робочої копії; залежності відтоді не змінювалися.
- `npm run generate:types`, `npm run generate:importmap`: повторно успішні після виправлення контрасту.
- `git diff --exit-code -- src/payload-types.ts "src/app/(payload)/admin/importMap.js"`: успішно.
- `npm run lint`: без помилок; старе попередження про невикористаний `dirname` у `src/collections/Media.ts:19`. Фінальна окрема перевірка зміненого компонента й браузерного тесту також успішна.
- `npm run test:int -- --maxWorkers=2`: **86 файлів, 653 тести успішні**, без пропусків. Залишилося попередження про відсутній `expo/tsconfig.base` окремого apps/manager при встановленні лише кореневих залежностей; тестам воно не завадило.
- `npm run build`: успішно, включно з перевіркою 16 міграцій, Turbopack, TypeScript і генерацією сторінок.
- `npm run test:e2e -- tests/e2e/local-fonts.e2e.spec.ts tests/e2e/booking-accessibility.e2e.spec.ts --workers=1 --reporter=line`: **5 тестів успішні**, локальна production-збірка, `DEVICE_TEST_BASE_URL=http://localhost:3011`.
- `git diff --check`: успішно.

Усі чотири файли шрифтів повернули HTTP 200; запитані накреслення завантажилися, запитів Google Fonts не було при блокуванні цих хостів. Перевірені сторінки не мають горизонтального переповнення. Axe не знайшов serious/critical порушень у перевіреному наборі. Перевірено клавіатуру, мобільне меню, touch targets, reduced motion, reflow та діалог запису без створення запису.

Розрахований контраст нового #332c2f: **5,93:1** на лавандовому фоні Buy та **8,89:1** для підпису Rent. Мінімум для цих текстів — 4,5:1. Soft assertions дозволяють завершити всі перевірки, але за будь-якого порушення тест залишається невдалим.

## Безпека, приватність, SEO та кеш

Секретів, клієнтських записів і вмісту листів у змінах немає. Використано синтетичні налаштування провайдерів; листи й оплати не запускалися. SHA-256 захищає від випадкової заміни файлів, але не є аудитом постачальника шрифтів.

Семантика HTML, metadata, canonical, robots, sitemap та приватні URL не змінені. Шрифти отримують content-hashed адреси того самого сайту; окрема інвалідація Payload-кешу не потрібна. Welcome offer, повторні записи та Stripe не змінювалися.

## Обмеження та наступний крок

Повні файли шрифтів займають 726 216 байтів (приблизно 709 КіБ), більше за латинські піднабори Google. Це виправлення надійності, не оптимізація розміру. Не стверджується піксельна тотожність між версіями або пристроями. Автоматична браузерна перевірка — Chromium; Vercel і реальний телефон ще потребують перевірки.

**Наступний точний крок:** stage лише перелічених файлів → commit → push `codex/self-host-boutique-fonts` → focused font hotfix PR. Після погодження інтеграції — оновити PR #63 та завершити Preview-перевірку листа з кодом, його одноразовості й тестової оплати. Коміту, push, merge або Production redeploy в межах цієї перевірки не виконано.
